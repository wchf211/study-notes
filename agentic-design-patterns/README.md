# Master Agentic Design Patterns — 笔记

14 teaching lessons + 2 breakout + 1 mock（练习类跳过），\~3h。不是讲某个框架，而是讲 harness 的 pattern 目录：先把 agent 的 building blocks 讲清，再给 5 个可组合的 design pattern（chaining / routing / parallelization / orchestrator-worker / evaluator-optimizer），最后用两个端到端 case（research system、coding agent）把 pattern 拼回真实系统。每篇带 4 道自测题，verbose 自包含风格；每篇末尾另有“这门课怎么教的”小节，记录值得偷到技术讲解里的讲法。

- [Five Patterns](agentic-design-patterns/patterns-02-five-patterns.md) —— chaining / routing / parallelization / orchestrator-worker / evaluator-optimizer
- [Case Studies + Wrap-up](agentic-design-patterns/patterns-03-case-studies.md) —— multi-agent research、coding agent、build ladder
